# Global Diagnosis Exam

A chairside teaching tool for the Global Diagnosis system of Robbins and Rouse (4 global
diagnoses, 5 CORE questions, 6 tools). Enter the exam measurements and the page names the global
diagnoses, primary and secondary treatments and sequencing considerations live, then builds a
plain-text note to paste into the chart.

**Use it:** https://rarcemunoz-repo.github.io/gdx/

- Nothing is saved or sent. Everything runs in your browser, and refreshing clears it.
- Do not enter patient names or chart numbers.
- Clinical judgment governs. The decision rules operationalise the book and are listed on the References tab.

| File | What it is |
|---|---|
| `index.html` | The whole tool, and the master copy |
| `docs/framework.md` | Normative values and the source for each rule |
| `docs/reading-list.md` | Curated PubMed reading list (406 records) |
| `tests/check-examples.js` | Regression check of the 12 worked examples |
| `CLAUDE.md` / `CONTRIBUTING.md` | Rules for Claude sessions and for human editors |

Maintained by Roger Arce with Ali B. Source: Robbins JW, Rouse JS. *Global Diagnosis: A New Vision of
Dental Diagnosis and Treatment Planning.* Quintessence; 2016. This repository contains no text from the book.
